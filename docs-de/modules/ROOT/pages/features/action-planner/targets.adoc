= Aktionsplaner - Ziele
:page-navtitle: Aktionsplaner - Ziele
:description: Tool zur Erstellung von Angriffsplänen von einzelnen Accounts bis hin zu Plänen für ganze Stämme
:keywords: Planung, Offaktionen, Angriffspläne, Ziele, Filter, Template etc.
:toc: macro
:toclevels: 2
:toc-title: Inhalt

Nach der Auswahl der Herkunftsdörfer unter xref:features/action-planner/source.adoc[Aktionsplaner - Herkunft] können unter diesem Punkt die Ziele für die Angriffe definiert werden.
Die Möglichkeiten sind auf folgende Tabs verteilt:

*Stämme / Spieler · Dörfer · Zonen · Abhängigkeiten*

TIP: Über das Dörfer-Popup auf der Karte kannst du jederzeit nachsehen, welche Zieldörfer sich aus den aktuellen Einstellungen ergeben (Anzahl Angriffe und Dörfer).

== Stämme/Spieler

image::features/action-planner/ziele/ziele_staemme_spieler.png[Tab "Stämme / Spieler" der Ziele mit hinzugefügter Front]

Zunächst besteht die Möglichkeit einer automatischen Zielauswahl eines Spielers oder eines Stammes.
Dies geschieht über den Button "Front hinzufügen".
Hier müssen auf der linken Seite unter *"Eigener Stamm / Spieler"* alle befreundeten Stämme (die Front zu den Zielstämmen haben) ausgewählt werden, auf der rechten Seite unter *"Feindesstamm / Spieler"* analog dazu alle Zielstämme.
Basierend auf der Lage der beiden Stämme werden alle Dörfer des Zielstammes ausgewählt, die innerhalb der eingestellten Frontentfernung zum eigenen Stamm liegen.

Pro Front stehen folgende Einstellungen zur Verfügung:

* *Frontentfernung*: Über den Regler wird definiert, wie viele Reihen der Front zu den eingetragenen Stämmen als Ziele ausgewählt werden sollen.
Hier kann sowohl eine Mindestdistanz (ab einer gewissen Entfernung zum eigenen Stamm) definiert werden als auch eine Maximaldistanz (wie weit in den Stamm hinein sollen die Angriffe gehen).
* *Dorfpunkte*: Mindest- und Maximalpunktzahl der Zieldörfer.
* *Min Nachbarn* / *Radius*: Definition von Zecken (siehe unten).
* *Anzahl Angriffe pro Dorf*: Wie viele Angriffe auf jedes Zieldorf dieser Front geplant werden sollen.
* *Einzeichnen*: Zeigt die ausgewählten Zieldörfer dieser Front auf der Karte an.

=== Definition von Zecken

Analog zu der xref:features/action-planner/source.adoc#definition_frontlinie[Definition von Zecken bei Herkunftsdörfern] kann hier definiert werden, welche Dörfer bei der Bestimmung der Frontlinie ignoriert werden.

Als Frontdörfer werden Dörfer ignoriert, die weniger befreundete Dörfer in dem unter Radius definierbaren Radius haben als in dem Mindestwert definiert worden ist.

====
Beispiel: Bei der Standardeinstellung "mindestens 5 Dörfer in einem 5-Feld-Radius" werden nur Dörfer in die Frontbewertung einbezogen, die in einem Radius von 5 Feldern mindestens 5 weitere Stammesdörfer haben.
Sollte ein Dorf weniger Dörfer in dem festgelegten Radius haben, so wird es als Zecke behandelt und somit nicht für die Frontbewertung mit einbezogen.
====

TIP: Es können auch mehrere von den oben beschriebenen Auswahlmöglichkeiten kombiniert werden.
Dazu klicke einfach erneut auf "Front hinzufügen".
Dies dient dazu, z.B. mehrere Zielstämme mit unterschiedlicher Angriffs-Anzahl pro Dorf als Ziel auszuwählen, oder aber auch unterschiedliche Gebiete des gleichen Gegners mit unterschiedlichen Angriffszahlen zu versehen. Ein klassischer Anwendungsfall hierfür wäre z.B., dass auf frontnahe Dörfer mehr Fake-Angriffe geplant werden als auf Dörfer, die weiter hinten liegen.

NOTE: Auf Casual-Welten werden Startdörfer von Spielern nie als Zieldorf ausgewählt, wenn als Einheitentyp das Adelsgeschlecht gewählt ist (siehe xref:features/action-planner/overview.adoc#casual-schutz[Casual-Schutz]). Diese Dörfer werden im Dörfer-Popup unter "Dörfer wegen Casual-Startdorfschutz entfernt" aufgeführt.

== Dörfer

image::features/action-planner/ziele/ziele_doerfer.png[Tab "Dörfer" der Ziele]

Der Tab "Dörfer" bietet drei Möglichkeiten, Ziele unabhängig von der automatischen Frontauswahl festzulegen:

=== Manuelle Dorfauswahl

Hier kann eine Koordinatenliste eingefügt und definiert werden, wie viele *Angriffe* auf jedes dieser Dörfer geplant werden sollen.
Die Dörfer werden zusätzlich zu den über Stämme / Spieler ausgewählten Zielen verplant.
Über die Checkboxen können mehrere Dörfer markiert und gemeinsam bearbeitet oder entfernt werden.

=== Ziele aus einem anderen Plan übernehmen

Alle Ziele, die in der letzten Berechnung eines anderen Plans einen Angriff erhalten haben, werden auch als Ziel in diesen Plan aufgenommen.
Dazu wird der Plan ausgewählt und unter *Angriffe pro Dorf* festgelegt, wie viele Angriffe auf jedes dieser Dörfer geplant werden sollen.
Die eingetragene Anzahl kann nachträglich bearbeitet werden.

TIP: Typischer Anwendungsfall: Auf alle Dörfer, auf die im AG-Plan ein Train geplant wurde, sollen im nächsten Plan Zwischencleaner oder Unterstützungen geplant werden.

=== Dörfer ausschließen

Sollen explizit Dörfer nicht angegriffen werden, können diese hier über eine Koordinatenliste ausgeschlossen werden – unabhängig davon, über welchen Weg sie als Ziel ausgewählt wurden.

== Zonen

image::features/action-planner/ziele/ziele_zonen.png[Tab "Zonen" der Ziele]

Ebenso wie bei den xref:features/action-planner/source.adoc#zonen[Herkunftsdörfer - Zonen] kann hier durch das Zeichentool auf der Karte durch einen oder mehrere gezeichnete Bereiche der Zielbereich weiter eingeschränkt werden.
Auch hier können Zonen als *Ausschließend* markiert werden, um Dörfer innerhalb der Zone explizit nicht als Ziel zu verwenden.

== Abhängigkeiten

image::features/action-planner/ziele/ziele_abhaengigkeiten.png[Tab "Abhängigkeiten" der Ziele]

Ebenfalls analog zu den xref:features/action-planner/source.adoc#abhaengigkeiten[Abhängigkeiten der Herkunft] können hier Abhängigkeiten für die Zieldörfer eingestellt werden.
Diese Abhängigkeiten dienen dazu, entweder Ziele gänzlich zu ignorieren, auf die bereits Angriffe geplant worden sind, oder lediglich die Anzahl der Angriffe eines bestehenden Plans von der im neuen Plan gewollten Gesamtanzahl Angriffe abzuziehen.

* *Anzahl abziehen*: Zieht für jedes Zieldorf die Anzahl der bereits geplanten Angriffe von der Anzahl gewollter Angriffe ab.
(Beispiel: Plan A hat 2 Angriffe auf Dorf X verplant → Plan B will 3 Angriffe pro Dorf. Mit der Abhängigkeit zu Plan A wird auf Dorf X nur noch 1 Angriff gesucht.)
* *Ausschließen*: Schließt Dörfer aus, auf die bereits ein Angriff geplant ist.
(Beispiel: Wenn mehrere AG-Pläne erstellt werden, werden Dörfer ausgeschlossen, auf die bereits ein Train geplant ist.)

====
*Beispiel:* Es sollen Fakes auf einen großen Stamm geplant werden. Hierzu sollen sowohl Rammen-Fakes (1 Ramme / fake/4+1 LKav) als auch Kata-Fakes (fake/8+1 Katas) verwendet werden.
Es werden also zunächst alle Rammen-Fakes verplant, diese reichen aber nicht, um alle Ziele abzudecken.
Also wird ein neuer Plan mit Katapulten in der Vorlage erstellt.
Damit nun aber nicht auf die Ziele, auf die bereits eine gewisse Anzahl an Fakes geplant ist, nochmal Fakes verplant werden, kann die bereits geplante Fake/Dorf-Anzahl von der jeweiligen Gesamt-Fake-Anzahl abgezogen werden.
Dadurch wird sichergestellt, dass z.B. nicht 2x 15 Angriffe pro Dorf geplant werden, sondern alle Dörfer auf 15 Fakes aufgefüllt werden.
====

Darüber hinaus können bereits verplante Ziele auch ganz ausgeschlossen werden.
Dies dient z.B. dazu, wenn AGs in mehreren Plänen geplant werden, die bereits verplanten Ziele auszuschließen, um doppelte AG-Planung zu umgehen.
