Powerful programming interfaces (APIs) are provided by TW Forge to enable automated and external access to platform functions and data.
The APIs are aimed primarily at developers who wish to build their own tools, scripts, or integrations around TW Forge.

== Official API Documentation

A complete and always up-to-date description of all available endpoints, parameters, authentication mechanisms, and example requests can be found in the official API documentation:

link:https://docs.twforge.net/developer-api[Official TW Forge API Documentation]

== Usage Notes

The use of certain APIs may be subject to specific prerequisites or permissions depending on the scope of functionality and access type.
Some APIs are accessible to all users, while others are reserved for premium users.
Details are also described in the API documentation.
